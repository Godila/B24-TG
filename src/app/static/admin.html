ЧатМост панель управления

Линии

Линия — подключённый номер мессенджера. Номер с одним участником — личный; добавьте участников, и он станет общим: переписка видна всем, отвечает любой участник, наблюдатель только читает.

Менеджеры

Список менеджеров подтягивается из пользователей Битрикс24.

Шаблоны

Быстрые ответы: панель «Шаблоны» под полем ввода в чатах. Тег — необязательная группировка.

Настройки

Как переписка с клиентами попадает в CRM.

Создавать для новых клиентов:

«Сделки» — контакт + сделка; «Лиды» — только лид, контакт и сделку создаст конвертация. Режим касается новых клиентов: существующие диалоги остаются на своих карточках. Канал связи (Telegram/MAX) пишется в поле «Источник».

Источник карточек CRM:

Выбранная запись подставляется в поле «Источник» новых карточек (название в CRM — то, что у записи в справочнике). Новые записи заводит scripts/add_max_source.py / add_wa_source.py. Telegram: выбранного источника нет в CRM. MAX: выбранного источника нет в CRM. WhatsApp: выбранного источника нет в CRM.

Прикреплять файлы к комментариям CRM:

«Только первое» — в карточку сделки попадает комментарий о новом диалоге, остальная переписка живёт во вкладке чата. «Все сообщения» — полный аудит в таймлайне. Уведомления менеджеру о новых клиентах работают в любом режиме.

Автоответы
Рабочие часы (для ответа вне времени):

Вне рабочих часов клиенту уходит только текст «нерабочего времени» — не чаще раза в сутки на диалог и не после ответа менеджера. Автоответ не снимает «Ожидают ответа». Часовой пояс — база IANA (Europe/Moscow).
